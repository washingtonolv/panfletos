# Logos das marcas

Coloque aqui os arquivos PNG, JPG, JPEG, WebP ou SVG das marcas. Exemplo de nome: `O-Boticario.png` (rótulo “O Boticario”). Os arquivos aparecem automaticamente no seletor após compilar/publicar o projeto. Use nomes únicos e estáveis: projetos guardam o nome completo do arquivo, incluindo extensão. Não renomeie uma logo já utilizada sem manter o arquivo anterior.

Prefira PNG/WebP transparente ou SVG confiável, com margens pequenas ao redor da arte. SVG é renderizado como imagem, nunca inserido como HTML. Esta pasta não contém logos de demonstração: as imagens oficiais devem ser fornecidas pelo responsável pelo projeto.
